# SEO-практика № 7 — стенд DemoShop

## Состав проекта

- `before.php` — исходная страница с намеренно допущенными SEO/структурными недостатками.
- `style.css` — оформление обеих версий.
- `assets/novabook.svg` — учебное изображение товара.
- `catalog/noutbuki/novabook-14/index.php` — оптимизированная карточка с читаемой структурой каталога.

## Запуск в OpenServer

Скопируйте папку `SEOLab` в корень проекта DemoShop под OpenServer. Откройте исходник по адресу `/seo_lab/before.php`, а итоговую страницу по адресу `/seo_lab/catalog/noutbuki/novabook-14/`.

## Что исправлено

Общий title заменен на уникальный, добавлены description и canonical, указан язык `lang="ru"`, оставлен один H1, заголовки разделены на H2/H3, добавлены семантические header/nav/main/article/section, содержательный alt, хлебные крошки и осмысленные внутренние ссылки. Короткая общая фраза заменена описанием характеристик и сценариев использования.

## Обратите внимание на относительные пути

Итоговая страница расположена на три уровня глубже корня SEO-стенда. Поэтому таблица стилей подключена как `../../../style.css`, изображение — `../../../assets/novabook.svg`.

Canonical в примере использует зарезервированный учебный домен `demoshop.example`. На реальном опубликованном сайте его нужно заменить на настоящий URL.
