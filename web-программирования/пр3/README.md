# Практическая работа № 3 — DemoShop CRUD

## Структура

- `database.sql` — создает базу `demoshop`, таблицу `products`, добавляет три начальных товара, если таблица пуста. Скрипт не удаляет существующие товары.
- `db.php` — подключение PDO. Проверьте `host`, `port`, `user` и `pass` под настройки OpenServer.
- `test_connection.php` — простая проверка соединения.
- `index.php` — чтение и показ каталога.
- `create.php` — добавление товара (INSERT).
- `edit.php` — загрузка товара и обновление (SELECT/UPDATE).
- `delete.php` — удаление по id через POST.
- `style.css` — оформление интерфейса.

## Запуск в OpenServer

1. Импортируйте `database.sql` через phpMyAdmin (вкладка SQL). Начальные товары вставятся, если таблица `products` пуста.
2. Поместите папку `PHP_Practice3` в каталог проектов OpenServer или в `public`-папку проекта Open Server Panel, как настроено преподавателем.
3. Откройте `test_connection.php` через локальный адрес. Если соединение не работает, измените параметры в `db.php`.
4. Откройте `index.php`, добавьте товар, отредактируйте его и удалите тестовую запись.

Проект подготовлен для учебного локального окружения. Запуск к MySQL/OpenServer в текущей среде не выполнялся; пароли/порт необходимо сверить с конкретной установкой.
