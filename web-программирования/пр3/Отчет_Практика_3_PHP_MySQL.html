Подключение и чтение данных

Подключение PDO

В db.php собраны параметры подключения и создание объекта PDO. Остальные PHP-файлы подключают его через require __DIR__ . '/db.php'. Режим ошибок настроен на исключения, а формат выборки — на ассоциативный массив.

$dsn = "mysql:host=$host;port=$port;dbname=$db;charset=$charset";
$options = [
  PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION,
  PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC,
  PDO::ATTR_EMULATE_PREPARES => false,
];
$pdo = new PDO($dsn, $user, $pass, $options);

Read — index.php

Главная страница выполняет SELECT-запрос, получает записи через fetchAll() и выводит таблицу товаров. Числовые значения приводятся к числу, строки выводятся через htmlspecialchars().

$stmt = $pdo->query(
  'SELECT id, name, category, price, stock
   FROM products ORDER BY id DESC'
);
$products = $stmt->fetchAll();

Безопасный вывод

Текстовые поля из базы выводятся через htmlspecialchars($value, ENT_QUOTES, 'UTF-8'), чтобы специальные символы пользователя отображались как текст, а не как HTML-разметка.

Подготовленные запросы

Пользовательские данные передаются отдельными параметрами через prepare() и execute(), а не склеиваются с SQL-строкой. Это позволяет безопасно обрабатывать введенные значения.

$stmt = $pdo->prepare(
  'INSERT INTO products (name, category, price, stock)
   VALUES (:name, :category, :price, :stock)'
);
$stmt->execute([
  'name' => $name,
  'category' => $category,
  'price' => (float)$price,
  'stock' => (int)$stock,
]);

Проверка введенных значений

Перед INSERT и UPDATE проверяются непустые название и категория, неотрицательная числовая цена и целый неотрицательный остаток. Для цены поддерживается ввод с запятой или точкой.

Безопасное удаление

Удаление допускается только POST-запросом. Значение id валидируется как положительное целое число, а SQL DELETE содержит WHERE id = :id, чтобы удалить только одну выбранную запись.

После успешных INSERT/UPDATE/DELETE пользователь перенаправляется на index.php. В CRUD-запросах используются условия по id.

Скриншоты для приложения к отчету

Для окончательной сдачи рекомендуется добавить скриншоты с локального OpenServer: таблица products в phpMyAdmin, главная страница с товарами, форма добавления, результат изменения и результат удаления. В текущей среде подключение к локальной MySQL не запускалось, поэтому изображения фактического браузерного результата не подменялись макетами.

Проверочный SQL database.sql не удаляет существующие товары: начальные записи добавляются только если таблица пуста. Это позволяет безопаснее повторно импортировать файл.

Вывод

В ходе практической работы подготовлено PHP-приложение DemoShop, связанное с базой MySQL через PDO. Создана таблица products с первичным ключом и полями для названия, категории, цены и остатка.

Реализованы все четыре операции CRUD: SELECT для просмотра товаров, INSERT для добавления, UPDATE для редактирования и DELETE для удаления записи. Для данных форм используются подготовленные запросы, серверная проверка и безопасный вывод.

Закреплено понимание связи браузера, PHP, PDO и MySQL: браузер отправляет запрос, PHP выполняет SQL через PDO, база возвращает или изменяет записи, после чего PHP формирует HTML-ответ.

Контрольные вопросы — краткие ответы

Что означает CRUD? Create, Read, Update, Delete — создание, чтение, изменение и удаление.

Для чего нужен PDO? Для подключения PHP к базе и выполнения запросов.

Зачем prepare() и execute()? Чтобы отдельно подготовить SQL и передать значения параметрами, не склеивая пользовательский ввод с запросом.

Почему важен WHERE в UPDATE/DELETE? Он ограничивает действие конкретной записью.

Зачем htmlspecialchars()? Для безопасного отображения текстовых значений в HTML.
