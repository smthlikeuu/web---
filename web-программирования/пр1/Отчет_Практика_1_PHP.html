Цель и план работы

Цель

Запустить PHP-сценарий через локальный web-сервер, освоить вывод, переменные, вычисления и условия, а затем создать HTML-формы с передачей данных методами GET и POST, проверкой и безопасным выводом.

Состав файлов проекта

index.php — итоговая форма «Имя + группа»; get.php — демонстрационный этап GET; student.php — самостоятельная форма «Фамилия и имя + специальность».

PHP выполняется сервером. Проект следует открыть через локальный адрес OpenServer, а не двойным щелчком по PHP-файлу.

Решение и проверка

Ключевой фрагмент POST-обработчика

if ($_SERVER["REQUEST_METHOD"] === "POST") {
    $name = trim($_POST["name"] ?? "");
    $group = trim($_POST["group"] ?? "");

    if ($name === "" || $group === "") {
        $message = "Заполните оба поля.";
    } else {
        $safeName = htmlspecialchars($name, ENT_QUOTES, "UTF-8");
        $safeGroup = htmlspecialchars($group, ENT_QUOTES, "UTF-8");
        $message = "Здравствуйте, $safeName! Ваша группа: $safeGroup.";
    }
}

Значение применённых средств

СредствоНазначение
$_GET / $_POSTПолучение параметров из запроса соответствующего HTTP-метода.
?? ""Использование пустой строки, если параметр отсутствует.
trim()Удаление пробелов по краям строки перед проверкой.
ifПроверка, заполнены ли необходимые поля.
htmlspecialchars()Экранирование специальных символов при выводе пользовательского текста в HTML.

Имя и группа заполненыПоказывает приветствие и группу.

Проверки описывают ожидаемое поведение кода. Локальный запуск через OpenServer в текущей среде не выполнялся.

Вывод

В ходе практической работы были подготовлены PHP-сценарии для запуска через OpenServer. Создана форма «Имя + группа» с передачей данных методом POST, демонстрационная GET-форма и самостоятельная страница карточки студента.

Для обработки данных применены суперглобальные массивы $_GET и $_POST, оператор ??, функция trim() и условные конструкции if. Перед выводом введённые пользователем значения преобразуются функцией htmlspecialchars(), а пустые поля отклоняются серверной проверкой.

Закреплено понимание клиент-серверной схемы: браузер отправляет запрос, локальный сервер запускает PHP, PHP формирует ответ, который браузер отображает пользователю.

Контрольные вопросы — краткие ответы

Почему PHP запускают через OpenServer? PHP-код выполняется серверным интерпретатором, браузер сам его не исполняет.

Для чего нужен name у input? Это имя поля, под которым его значение передаётся серверу.

Где видны GET-параметры? Обычно в URL после вопросительного знака.

Чем различаются $_GET и $_POST? Они читают данные, переданные соответствующими методами формы.

Зачем нужны trim() и htmlspecialchars()? Первая удаляет пробелы по краям, вторая безопасно экранирует специальные HTML-символы при выводе.
