# Практическая работа № 1 — серверные сценарии PHP

## Состав проекта

- `index.php` — итоговая форма «Имя + группа», обработка POST, проверка пустых полей и безопасный вывод.
- `get.php` — отдельная демонстрация GET-передачи имени и получения значения через `$_GET`.
- `student.php` — самостоятельное задание «Карточка студента» с POST и безопасным выводом.

## Запуск через OpenServer

Для классического OpenServer поместите папку `PHP_Practice1` внутрь `domains` и откройте соответствующий локальный адрес, например `http://practice1.local/`. Для Open Server Panel 6.x используйте структуру проекта, настроенную преподавателем; обычно публичные файлы размещают в папке `public`.

PHP-файлы нужно открывать через локальный web-сервер, а не двойным щелчком из Проводника. После копирования проекта в каталог сервера перезапустите сервер, если этого требует установленная версия OpenServer.

## Проверка

1. Откройте `get.php`, отправьте имя и убедитесь, что параметр отображается в URL.
2. В `index.php` отправьте заполненные имя и группу: появится приветствие.
3. Оставьте одно или оба поля пустыми: появится сообщение о необходимости заполнить поля.
4. Введите в имя строку `<b>Иван</b>`: она будет показана как текст, а не интерпретирована как HTML.
5. Повторите заполнение и проверку в `student.php`.

> Файлы подготовлены, но запуск на локальном OpenServer в текущей среде не проверялся. ФИО и группа оставлены для заполнения студентом.
