# Практическая работа № 2 — Файловый ввод-вывод, Cookie и Session

## Состав проекта

- `index.php` — мини-проект «Мой учебный кабинет»: имя в Session, группа в Cookie, заметки в `notes.txt`.
- `file_demo.php` — запись и чтение `message.txt`.
- `cookie_demo.php` — создание, чтение и удаление Cookie.
- `session_demo.php` — счетчик открытий страницы в Session.
- `session_logout.php` — завершение Session.
- `task.php` — самостоятельное задание «Моя дисциплина»: имя в Session, технология в Cookie на час, комментарии в `comments.txt`.

## Запуск

Поместите каталог `PHP_Practice2` в `domains` OpenServer или в настроенный каталог проекта Open Server Panel. Откройте локальный адрес через браузер. Для самостоятельной работы начните с `task.php`.

PHP-сценарии необходимо запускать через локальный сервер, а не открывать напрямую с диска. Файлы `notes.txt` и `comments.txt` создаются автоматически при первой записи; каталогу проекта требуются права на запись со стороны PHP.

## Результаты

- Файловая запись выполняется с `FILE_APPEND`, поэтому прежние строки сохраняются.
- Cookie используются для небольших настроек группы или технологии.
- Session хранит имя и счетчик текущего сеанса.
- Перед выводом пользовательские значения обрабатываются `htmlspecialchars()`.

> PHP-скрипты созданы, но запуск на OpenServer в этой среде не выполнялся. Поля ФИО и группы в отчете нужно заполнить вручную.
