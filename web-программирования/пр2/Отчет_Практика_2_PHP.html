Цель и основные понятия

Цель работы

Научиться сохранять данные между HTTP-запросами в простом PHP-приложении: записывать и читать файлы, создавать и получать Cookie, использовать Session и сравнивать эти механизмы хранения.

В самостоятельном задании «Моя дисциплина» имя сохраняется в Session, выбранная web-технология — в Cookie на один час, комментарии — в comments.txt.

Результаты выполнения

Файловый ввод-вывод

В file_demo.php текст принимается через POST, проверяется после trim(), записывается в message.txt. Перед чтением проверяется file_exists(). В index.php и task.php новые строки добавляются в notes.txt и comments.txt с флагом FILE_APPEND, поэтому прежние записи не удаляются.

file_put_contents(
    __DIR__ . "/notes.txt",
    $line,
    FILE_APPEND | LOCK_EX
);

if (file_exists($notesPath)) {
    $notes = file_get_contents($notesPath);
}

Cookie

cookie_demo.php позволяет установить демонстрационный Cookie на час, прочитать его из $_COOKIE и отправить браузеру команду удаления с временем в прошлом. В учебном кабинете Cookie используется для хранения группы, а в самостоятельной работе — выбранной технологии.

setcookie("technology", $technology, time() + 3600, "/");
$technology = $_COOKIE["technology"] ?? "";
Новое Cookie становится доступным в $_COOKIE в следующем HTTP-запросе, поэтому для демонстрации после установки выполняется обновление страницы.

Session

В начале сценариев, использующих Session, вызывается session_start(). Имя студента хранится в $_SESSION["name"], а session_demo.php демонстрирует сохранение счетчика между запросами.

session_start();
$_SESSION["visits"] = ($_SESSION["visits"] ?? 0) + 1;
$visits = (int) $_SESSION["visits"];

Для завершения сеанса подготовлен session_logout.php: он вызывает session_start(), затем session_destroy() и перенаправляет пользователя.

Самостоятельное задание

Страница «Моя дисциплина»

В task.php создана форма с полями «Имя», «Любимая web-технология» и «Комментарий». Имя сохраняется в Session, технология — в Cookie на один час, комментарии дописываются в comments.txt.

Фрагмент решения

if ($_SERVER["REQUEST_METHOD"] === "POST") {
    $name = trim($_POST["name"] ?? "");
    $technology = trim($_POST["technology"] ?? "");
    $comment = trim($_POST["comment"] ?? "");

    if ($name === "" || $comment === "") {
        $message = "Имя и комментарий обязательны.";
    } else {
        $_SESSION["name"] = $name;
        if ($technology !== "") {
            setcookie("technology", $technology,
                      time() + 3600, "/");
        }
        $line = $name . " — " . $comment . PHP_EOL;
        file_put_contents(__DIR__ . "/comments.txt",
                          $line, FILE_APPEND | LOCK_EX);
    }
}

Безопасный вывод

Перед отображением введенных значений в HTML используется htmlspecialchars($value, ENT_QUOTES, "UTF-8"). Это сохраняет пользовательский текст текстом и не позволяет интерпретировать введенные теги как разметку. Функция trim() применяется перед проверкой обязательных значений.

Вывод

В ходе практической работы были изучены три способа сохранения состояния в PHP. Файлы хранят данные на диске сервера, Cookie — небольшие значения в браузере пользователя, а Session позволяет серверу хранить данные текущего сеанса.

На практике реализованы запись и чтение файла, добавление новых строк с FILE_APPEND, проверка существования файла, создание/чтение/удаление Cookie и использование Session для хранения имени и счетчика.

В самостоятельной части создана страница «Моя дисциплина»: имя сохраняется в Session, web-технология — в Cookie, комментарии — в файле. Перед выводом пользовательские значения экранируются через htmlspecialchars(), а обязательные поля проверяются после trim().

Контрольные вопросы — краткие ответы

Что делает FILE_APPEND? Добавляет данные в конец файла, сохраняя прежнее содержимое.

Где хранится Cookie? В браузере; сервер получает его в следующем запросе через $_COOKIE.

Для чего нужен session_start()? Чтобы создать или продолжить пользовательскую сессию и получить доступ к $_SESSION.

Почему setcookie() и session_start() вызываются до HTML? Они отправляют HTTP-заголовки, которые должны быть сформированы до начала вывода тела страницы.

Зачем нужен htmlspecialchars()? Для безопасного вывода пользовательского текста в HTML.
