# Практическая работа № 4 — DemoShop

## Перед запуском

Скопируйте сюда файлы из `PHP_Practice3`: `db.php`, `style.css`, а также CRUD-страницы `index.php`, `create.php`, `edit.php`, `delete.php`. В этой папке доступны `admin_guard.php`, который нужно подключить в начало каждого CRUD-файла перед db.php, и `shop.css`. Обновите настройки db.php под ваш OpenServer.

## Что здесь подготовлено

- `database.sql` — таблица `users` и проверочная структура `products`.
- `register.php`, `login.php`, `logout.php` — создание аккаунта, вход и выход.
- `profile.php`, `my-data.php` — защищённый профиль и самостоятельная часть.
- `admin_guard.php`, `admin.php` — проверка роли администратора.
- `catalog.php`, `product.php` — публичный каталог и карточка товара.
- `api/product.php` — JSON API для AJAX-обновления цены и остатка.

## Порядок проверки

1. В phpMyAdmin выполните `database.sql` в базе `demoshop`.
2. Зарегистрируйте тестового пользователя и проверьте в таблице `users`, что `password_hash` содержит хеш.
3. Войдите, проверьте Session и профиль, затем выйдите.
4. Для теста админа измените роль тестовой записи на `admin`, затем войдите заново.
5. Проверьте защиту CRUD-файлов: без входа и с ролью user доступ должен быть запрещен.
6. Откройте `catalog.php`, карточку товара и напрямую `api/product.php?id=...`.
7. Измените цену/остаток товара в phpMyAdmin и нажмите AJAX-кнопку на карточке.

> Проект подготовлен, но запуск на OpenServer/MySQL в текущей среде не выполнен. Для административного теста используйте только учебный аккаунт; реальные пароли в отчёт и скриншоты не включайте.
